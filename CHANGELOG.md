# BYTE PHANTOM — Changelog

## v1.3.0 — PHANTOM SIGNAL / First Live Intelligence Module
- Repositioned the interface as a local-first Cybersecurity & Network Intelligence workstation.
- Added a HUD layer: host radar, targeting reticle, telemetry plates, neon edge lighting, and deeper Matrix/ASCII atmosphere.
- Added SYSTEM INTELLIGENCE, a real, read-only Windows host inventory.
- Reads Windows hostname and OS details, CPU model/core count, memory totals, disk capacity when available, and non-loopback IPv4 adapter metadata.
- No network probes, packet transmission, privilege escalation, or system configuration changes are performed.
- All other operation modules remain explicitly marked SIMULATION until implemented in later numbered releases.
- Version appears in the application, VERSION file, web/version.json, Windows EXE filename, and CI artifact names.
- Windows artifact: BYTE-PHANTOM-v1.3.0-Windows-x64.exe
- Android debug artifact: BYTE-PHANTOM-v1.3.0-Android-debug.apk
