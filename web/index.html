DIGITAL GHOST is evolving into a local-first Cybersecurity & Network Intelligence workstation. Version 1.20.0 adds DNS failover control. Windows can apply a repeat-stable resolver to the active adapter after explicit confirmation and a UAC Administrator prompt, with the original DHCP/static DNS settings backed up locally and a restore operation available.
